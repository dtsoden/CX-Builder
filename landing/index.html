Everything You Need to Build AI at Scale

From visual flow design to multi-agent orchestration, CX-Builder provides the complete toolkit for enterprise AI development.

Visual Drag-and-Drop Builder

Design AI workflows on an intuitive canvas. Three builder modes (Assistant, Chatflow, and Agentflow) scale from simple chatbots to complex multi-agent systems.

Multi-Agent Orchestration

Create teams of AI agents with supervisor-worker patterns. Agents collaborate, delegate tasks, and solve complex problems through hierarchical coordination.

RAG Pipelines Built In

Connect 39+ data sources including PDFs, databases, APIs and cloud storage, and build retrieval-augmented generation pipelines with pgvector-powered semantic search.

35+ LLM Integrations

OpenAI, Anthropic Claude, Google Gemini, Mistral, Groq, AWS Bedrock, and local models via Ollama. Switch providers without rewriting workflows.

Human-in-the-Loop

Keep humans in control with approval gates, review checkpoints, and input requests embedded directly into automated agent workflows.

Enterprise Security

Role-based access control, SSO, JWT authentication, encrypted credentials, rate limiting, and full audit trails. Deploy on-premises or in your cloud.

Full Observability

Execution traces, visual debugging, and integrations with LangFuse, LangSmith, and other analytics platforms for complete pipeline visibility.

Embeddable Chat Widget

Deploy your agents anywhere with a customizable chat widget, REST APIs, and TypeScript / Python SDKs for seamless integration.

50+ Ready-Made Templates

Customer support bots, RAG pipelines, SQL agents, research assistants, and multi-agent teams. Production-tested templates to start building instantly.

One-Line Install

From Zero to Running in 60 Seconds

Just Docker, nothing else required. No git clone, no manual config. The installer generates all secrets automatically and starts the full stack.

Linux / macOS
curl -fsSL https://raw.githubusercontent.com/dtsoden/CX-Builder/master/install.sh | bash
Windows (PowerShell)
irm https://raw.githubusercontent.com/dtsoden/CX-Builder/master/install.ps1 | iex
Auto-generates secure passwords, JWT secrets & database credentials
Starts the full stack: app server + pgvector PostgreSQL
Ready at localhost:9800. Open your browser and build

Independently maintained

CX-Builder is a fork of Flowise, which its original team discontinued in July 2026. CX-Builder tracks the final release, v3.1.4, and is maintained independently from that point on.

Nothing here depends on the upstream project continuing. The code is Apache 2.0, every package builds from source in this repository, and the container image is published separately. Self-hosted deployments keep running regardless.

Read the Flowise sunset notice, which explicitly encourages forks: the Apache 2.0 licensed code is yours to keep building on.
